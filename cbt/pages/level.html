Navigation Examples from B8T.html

Target File Path from B8T.html Explanation
dashboard.html ../../dashboard.html Go up two levels to pages folder
index.html ../../../index.html Go up three levels to root folder
logo.png ../../../assets/images/logo.png Go up three levels to root, then into assets/images
styles.css ../../../assets/css/styles.css Go up three levels to root, then into assets/css
users.json ../../../data/users.json Go up three levels to root, then into data
B7L.html ../B7L.html Go up one level to 2024 folder

Real-world HTML Example

From B8T.html, linking to different resources:

<!-- Link to dashboard -->
<a href="../../dashboard.html">Dashboard</a>

<!-- Link to home page -->
<a href="../../../index.html">Home</a>

<!-- Include CSS -->
<link rel="stylesheet" href="../../../assets/css/styles.css">

<!-- Include JavaScript -->
<script src="../../../assets/js/script.js"></script>

<!-- Display image -->
<img src="../../../assets/images/logo.png" alt="Logo">

<!-- Fetch data -->
<script>
fetch('../../../data/users.json')
  .then(response => response.json())
  .then(data => console.log(data));
</script>

Key Points to Remember

  • Each ../ moves up one folder level
  • Use relative paths (like ../../file.html) for resources within your site
  • Use absolute paths (like /assets/images/logo.png) for resources from the root
  • Always test your paths - broken links are a common issue
  • Modern frameworks often have specialized routing systems
