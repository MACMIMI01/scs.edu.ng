A Curated Compendium of HTML Tags

An organized reference for modern web development, based on HTML_Basic_Tags_Cheatsheet original script.

Essential & Modern Tags

<h1> to <h6> Essential

Defines headings. <h1> is the most important, <h6> is the least.

<p> Essential

Defines a paragraph.

<a> Essential

Defines a hyperlink. The href attribute specifies the destination URL.

This is a link

<img> Essential

Embeds an image. Requires src (source) and alt (alternative text) attributes.

<div> and <span> Essential

Generic containers. <div> is a block-level container for layout, and <span> is an inline container for styling text.

<ul>, <ol>, <li> Essential

Used for lists. <ul> for unordered (bulleted) lists, <ol> for ordered (numbered) lists, and <li> for each list item.

<strong> and <em> Essential

Semantic text tags. <strong> indicates importance (bold), and <em> indicates emphasis (italic).

Important Text and Emphasized Text

<table>, <tr>, <th>, <td> Essential for Data

Used to create tables for tabular data. Not recommended for page layout.

<form> and <input> Essential for Forms

<form> contains interactive controls for submitting user data. <input> is the primary form control element.

<header>, <footer>, <main>, <section>, <article>, <aside>, <nav>

HTML5 semantic elements. They provide meaning to your page structure, which is good for SEO and accessibility.

<audio> and <video>

Embeds sound and video content with native browser controls.

<details> and <summary>

Creates an interactive disclosure widget ("accordion") that the user can open and close.

Deprecated & Outdated Tags

<font> Deprecated

Used to define font size, color, and face. This is completely replaced by CSS.

Instead of <font color="blue">, use CSS: <p style="color: blue;">

<center> Deprecated

Used to center text and other content. This is completely replaced by CSS.

Instead of <center>, use CSS: <div style="text-align: center;">

<b> and <i>

Presentational tags for bold and italic text. While they still work, it's better to use <strong> and <em> which carry semantic meaning.

<strike> Deprecated

Defines strikethrough text. The modern equivalent is <s> (for text that is no longer correct) or <del> (for deleted text).

This item is sold out.

<acronym> Deprecated

Defines an acronym. The modern, preferred tag is <abbr> for all abbreviations.

The WHO was founded in 1948.

<frame>, <frameset>, <noframes> Deprecated

Used to create framesets, which split the browser window into multiple documents. This approach is outdated and has been replaced by <iframe> and modern CSS layouts.

<big> Deprecated

Made text one size larger. This should be done with CSS font-size.

<tt> Deprecated

Created "teletype" or monospaced text. The modern equivalent is <code>, <kbd>, or <samp>, or simply using CSS font-family: monospace;.
