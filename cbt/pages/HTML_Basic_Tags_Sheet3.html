The Ultimate HTML Elements Cheat Sheet

Document Structure

These tags define the overall structure and metadata of an HTML page.

<html>

The root element of an HTML page. All other elements are descendants of this tag.

<head>

Contains meta-information about the document, like the title, styles, and scripts. This content is not displayed on the page.

<body>

Contains the visible content of the webpage, such as text, images, links, and forms.

<title>

Sets the title of the browser tab or window. It's placed inside the <head>.

<link> and <style>

<link> connects to external resources like CSS stylesheets. <style> is used to write CSS directly inside the HTML file (inline/embedded styles).

<script>

Used to embed or link to JavaScript code to add interactivity to the page.

<meta>

Provides metadata such as character set (charset="UTF-8") or viewport settings for mobile responsiveness.

Containers & Layout

Generic container tags used for grouping content and structuring the page layout.

<div>

A block-level container. It takes up the full width available and is used to group large sections of content.

<span>

An inline-level container. It only takes up as much width as necessary and is used to group small pieces of content within a line, like a single word.

This is a paragraph with a styled span inside it.

<header>, <footer>, <main>, <section>

Semantic layout tags that describe their content. They function like <div>s but provide more meaning to the browser and developers.

Forms

Tags used to collect user input.

<form>

The main container for all form elements.

<input>

The most versatile form element. The type attribute changes its function (e.g., text, password, checkbox, radio, submit).

<label>

A caption for an <input> element. The for attribute links it to the input's id, making it clickable.

<textarea>

A multi-line text input field.

<select> and <option>

Creates a dropdown list. Each choice is defined by an <option> tag.

<button>

A clickable button, often used to submit a form.

Tables

Tags for displaying data in a tabular format.

<table>, <tr>, <th>, <td>

<table>: The main table container.
<tr>: Table Row. Defines a row of cells.
<th>: Table Header. A special cell for column headings (bold and centered).
<td>: Table Data. A standard data cell.

Media

Tags for embedding images, audio, and video.

<img>

Embeds an image. The src attribute specifies the image path, and the alt attribute provides alternative text for accessibility.

<video>

Embeds a video. The controls attribute adds play/pause buttons. The <source> tag specifies the video file.

<audio>

Embeds audio content. Works similarly to the video tag.
